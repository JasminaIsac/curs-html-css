# Prelegerea 3 — Fundamentele CSS

După editarea `src/parts/*.html` sau `src/template.html`, rulează `.\build.ps1`.

Formatul e același ca la Prelegerea 2 / `5-css-avansat`: secțiuni `section.lesson`, markdown în `script type="text/markdown"`, demo-uri `.demo` cu CSS vizibil, HTML și opțional `data-knobs`.

Pentru lecția asta, pune controale (`data-knobs`) oriunde o valoare merită comparată live: `color`, `font-size`, `text-align`, unități, `justify` nu — aici sunt proprietăți de text și casetă.

`sel` trebuie să fie exact textul selectorului din regula vizibilă, iar `prop` trebuie să existe deja în regulă.
